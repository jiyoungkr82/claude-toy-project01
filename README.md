# 🚀 AI-Powered Developer Portfolio

AI 기술(Claude Code)을 활용해 비즈니스 로직부터 배포까지 신속하게 구축한 **박지영의 개발자 포트폴리오**입니다. 

🔗 **라이브 데모**: [https://introduce-jiyoung.netlify.app/](https://introduce-jiyoung.netlify.app/)

## ✨ Key Features
- **AI-Driven Development**: `Claude 3.5 Sonnet` 및 `Claude Code(CLI)`를 활용한 고속 프로토타이핑
- **Responsive Design**: Mobile-First 기반의 반응형 웹 구현 (Tailwind CSS)
- **Interactive UI**: 사용자 경험을 고려한 부드러운 애니메이션 및 배지 호버 효과
- **Direct Contact**: `mailto:` 프로토콜을 활용한 원클릭 문의 기능

## 🛠 Tech Stack
### Frontend
- HTML5 / Tailwind CSS
- JavaScript (Vanilla JS)

### Tools
- **Claude Code**: AI 코딩 어시스턴트 (CLI)
- **Netlify**: 지속적 배포(CD) 및 호스팅
- **Git & GitHub**: 버전 관리 및 협업
